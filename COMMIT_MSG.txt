v1.2.3 — Финальный релиз DiscoveryFM

Полностью переработанное приложение радиостанции Discovery FM с подкастами.

== ЧТО СДЕЛАНО ==

[Радио-плеер]
- Полупрозрачный фон с фото/логотипом текущего исполнителя (источник: Deezer API)
- Автоматическое обновление фото при смене трека (опрос каждые 10 секунд)
- Индикатор статуса: «В эфире», «Офлайн», «Соединение...», «Ошибка»
- Регулятор громкости, кнопка play/pause, визуализатор звука

[Подкасты (АУДИОframes)]
- Новый раздел «АУДИОframes» вместо «Категории подкастов»
- Полная библиотека: 9 категорий, 765 подкастов (снят лимит 100)
- У каждого подкаста своя обложка (картинка из текста/PREVIEW_PICTURE)
- Длительность каждого подкаста (из API + ffprobe на сервере)
- Название категории над обложкой на экране плеера

[Описания подкастов]
- Бейдж «i» на обложке подкаста при наличии описания
- Клик по обложке — всплывающее окно с полным описанием
- Текст с выравниванием по ширине и прокруткой

[Поиск]
- Иконка поиска в шапке ВСЕХ экранов (главный, категория, плеер)
- Поиск по названию подкаста и по названию категории
- Поиск на лету, без учёта регистра
- Карточки результатов с обложкой и категорией

[Исправления]
- Названия подкастов очищаются от кавычек и HTML-сущностей (»," , &quot;)
- Повторное открытие играющего подкаста не перезапускает его
- Кнопка play/pause всегда корректно отражает состояние
- Версия внизу главного экрана: просто «v.2026»

## КЛЮЧЕВЫЕ ФАЙЛЫ

- MainActivity.kt — точка входа
- DiscoveryApp.kt — навигация, главный экран, плеер радио
- SearchScreen.kt — экран поиска (новый)
- CategoryScreen.kt — список подкастов категории
- PodcastPlayerScreen.kt — экран плеера подкаста с описанием
- DiscoveryViewModel.kt — состояния, поиск, кэш фото
- PodcastRepository.kt — загрузка подкастов из API
- PlaybackService.kt, PodcastPlayerManager.kt — воспроизведение
